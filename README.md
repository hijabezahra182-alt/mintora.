# MINTORA — To-Do App

MINTORA is a modern, responsive task-management app designed to make everyday tasks easier to organize and track.

It combines a fresh productivity-focused interface with practical JavaScript functionality, including task filtering, completion tracking, and browser-based data persistence.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Filter tasks by:

  * All
  * Active
  * Completed
* Clear completed tasks
* Automatic task statistics
* Persistent data using LocalStorage
* Empty-state interface
* Responsive design
* Smooth hover and interaction effects

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* LocalStorage API

## ⚙️ How It Works

Tasks are created through the input field and stored in the browser using **LocalStorage**.

When a task is added:

1. JavaScript creates the task object.
2. The task is saved to LocalStorage.
3. The task list is rendered dynamically.
4. Statistics are updated automatically.

Users can then complete, delete, or filter their tasks.

## 💾 LocalStorage

MINTORA uses the browser's LocalStorage API so tasks remain available even after refreshing or reopening the page.

This makes the application feel more like a real productivity tool without requiring a backend or database.

## 📊 Task Statistics

The app dynamically tracks:

* Total tasks
* Completed tasks
* Remaining tasks

Statistics update whenever the task list changes.
